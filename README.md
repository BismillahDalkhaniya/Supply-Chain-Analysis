## Supply Chain Analysis | Python & Power BI

## Project Overview

This project focuses on analyzing supply chain operations using Python and Power BI. The objective is to explore supply chain data, identify operational patterns, and develop an interactive dashboard to present important business metrics.

## Objectives

- Analyze supply chain performance.
- Understand inventory and stock levels.
- Examine shipping and manufacturing costs.
- Analyze product sales and revenue.
- Explore production volumes and defect rates.
- Build an interactive Power BI dashboard.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib / Seaborn
- Power BI
- DAX

## Project Workflow

1. Data Loading – Imported the supply chain dataset into Python.
2. Data Cleaning – Checked missing values, data types and data consistency.
3. Exploratory Data Analysis – Explored relationships between operational variables.
4. Data Preparation – Prepared cleaned data for visualization.
5. Dashboard Development – Created an interactive Power BI dashboard using KPIs, charts and slicers.

## Key Metrics

- Total Revenue
- Average Shipping Cost
- Average Manufacturing Cost
- Defect Rate
- Production and Inventory Metrics
